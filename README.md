# JobTrack

JobTrack is a full-stack job application tracking application built with Next.js, TypeScript, PostgreSQL, Prisma, and Better Auth.

## Features

- User registration and login
- Protected routes
- Create and manage job listings
- View job details
- Apply to jobs
- Track applications
- Update application status
- Dashboard with job and application statistics
- Relational database design using Prisma and PostgreSQL

## Tech Stack

- Next.js 16
- React
- TypeScript
- Tailwind CSS
- PostgreSQL
- Prisma ORM
- Better Auth
- Git & GitHub
- Vercel

## Application Statuses

- Applied
- Interview
- Offer
- Rejected
- Withdrawn
